# Titanic Survival Prediction 🚢

A Machine Learning project built to predict passenger survival outcomes on the Titanic based on historical demographic and voyage data.

---

## 🛠️ Technologies
* **Programming Language:** Python
* **Machine Learning & Data Science:** Scikit-learn, Pandas, NumPy
* **Environment:** Jupyter Notebook / VS Code
* **Version Control:** Git & GitHub

---

## 🌟 Features
* **Random Forest Classification:** Trained model predicting passenger survival outcomes with **72.63% accuracy**.
* **Custom Inference Function:** Evaluates survival probabilities and confidence scores for user-defined passenger profiles.
* **Reproducible Pipeline:** Clean, modular code structure from raw data to final predictions.

---

## 🔄 The Process
1. **Data Preprocessing:** Cleaned the historical dataset by handling missing values using median imputation and encoding categorical variables for model compatibility.
2. **Model Training:** Built and trained a Random Forest Classifier using Python and Scikit-learn.
3. **Evaluation:** Assessed model performance, achieving a 72.63% accuracy score on test data.
4. **Inference Setup:** Developed custom functions allowing user-defined passenger inputs (such as class, sex, age, and fare) to generate real-time survival predictions.
